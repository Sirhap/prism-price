卡网店铺对接码（分销码）查询与标注指南

对于数字商品分销与多店比价而言，店铺对接码（也称分销码、对接代码）是连接上游货源店铺与下游分销店铺的核心凭证。棱镜比价自动提取公开店铺名称与简介中的对接码，并在店铺卡片、店铺介绍页及专属目录中展示，支持一键复制。

浏览店铺对接码目录 → 在首页筛选含对接码店铺

如何在棱镜比价查找店铺对接码？

  1. 桌面端/手机端筛选：访问棱镜比价首页，点击顶部「看收录店铺」选项卡，勾选筛选栏中的「仅看有对接码」，即可筛选全部已识别到对接码的商家，点击卡片上的对接码胶囊即可复制。
  2. 静态目录直达：直接浏览 店铺对接码专题目录，查看每家店铺的系统类型（如联动小铺）、收录商品数量与对应对接码。
  3. 关键词检索：在店铺模式搜索框输入「对接码」或目标店铺名/关键词，快速锁定支持分销的源头店铺。

商家如何标注对接码才能被自动识别？

系统遵循严格的规则识别公开标注的对接码，支持简体与繁体中文标签。建议卡网店主在店铺名称或店铺简介中使用清晰且独立的格式标注：

  • 支持完整标签：对接码、对接代码、分销码（可跟冒号、空格或「为 / 是」）。
  • 支持带冒号简称：对接：、分销：（简称须紧跟冒号或等号 : / ： / =）。
  • 格式原样保留：系统会将对接码严格按字符串保存，保留字母大小写、前导零（例如 000001）与独立成行时的中间空格（例如 Lucky plus）。
# 推荐标注示例（建议在店铺简介中单独成行）
主营 ChatGPT / Codex / Claude / Gemini
对接码：your_code_01
分销码：「my_shop_code」

为什么有些店铺的对接码与链接后缀不同？

在联动小铺等卡网系统中，店铺访问路径标识（如 /shop/xxxx）与商户后台设置的实际分销对接码可以相同，也可以由店主自定义为不同字符。棱镜比价优先提取店主在名称或简介中最新公开标注的对接码，并在采集同步后自动更新。
