AI 订阅比价指南

棱镜比价（PRISM）收录公开卡网店铺的信息，整理 ChatGPT、Codex、Claude、Gemini、Cursor、Grok、DeepSeek 等 AI 订阅、API 中转与数字商品参考报价，支持多店同款比较、卡网店铺收录及店铺对接码检索。

ChatGPT / Codex / Claude / Gemini 比价指南 对照官方订阅定价与卡网成品号、代充、中转的差异与避坑清单。 店铺对接码（分销码）查询与规范 如何筛选有对接码的店铺，以及商家如何标注分销码以便收录识别。 卡网开店与联动小铺入驻指南 联动小铺开店流程、商品规范命名及提交至棱镜比价收录步骤。

如何查找与对比商品？

在比价首页搜索 ChatGPT、Codex、Claude、Gemini 等关键词，或直接进入品牌目录按品牌、商品类型（成品账号、代充/兑换码、API 中转、接码服务）、套餐、时长和价格筛选。展开同款商品后可对比不同店铺参考价并加入同台比价清单。

比较价格时要看哪些条件？

先确认商品的套餐、有效期、交付方式和使用条件是否相同。成品账号、官方代充、兑换码、接码服务和 API 中转可能对应不同的交付与风险结构，不能只按标价高低判断是否为同一规格。

如何按卡网系统与对接码查找店铺？

在首页切换至「看收录店铺」，可按联动小铺、云猫寄售、16688交易平台、独角数卡、二次元发卡等卡网系统类型筛选，也可勾选「仅看有对接码」一键复制分销对接码；亦可直接访问公开店铺目录与店铺对接码目录。

展示的价格和库存是否实时？

网站展示的是快照采集时获得的参考信息，可能与店铺当前状态存在时间差。下单前请点击前往源站店铺核实实时价格、库存和商品说明。

交易与售后由谁负责？

本站仅收录公开信息，不参与交易，也不对店铺商品、售后和风险负责。请自行核实商家的交付方式、质保条款与交易风险。
